# 실행 로드맵 ($0 to First Revenue)

## 핵심 원칙
> MindExtract는 그 자체로 수익을 내는 것이 아니라, **수주 프로젝트의 효율을 극대화하는 무기**다.  
> "첫 수익"은 **MindExtract를 사용한 첫 클라이언트 프로젝트 납품 대금**이다.

### 인프라 원칙
- **랜딩 사이트** (`mindextract.site`) → Vercel 무료 배포
- **내부 앱** → 맥북 로컬 실행 (호스팅 불필요)
- **총 운영 비용: $0~$1/월** (도메인만)
