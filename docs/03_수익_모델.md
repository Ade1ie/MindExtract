# 견적 산출 시스템 및 프로젝트 수익 관리

## 핵심 전환

> MindExtract의 수익은 구독료가 아니라 **클라이언트 수주 프로젝트 납품 대금**이다.
> 따라서 가격 정책이 아닌 **견적 정확도**와 **프로젝트 수익성 관리**가 핵심이다.

---

## 자동 견적 산출 시스템

### 견적 산출 공식

```
총 예상 시간 = (
    모듈 커스터마이징 시간 합계
    + 부분 모듈 추가 개발 시간 합계
    + 신규 기능 개발 시간 합계
    + 통합 테스트 (전체의 15%)
    + 배포 및 인프라 (고정 12시간)
    + 버퍼 (전체의 20%)
)

견적 금액 = 총 예상 시간 × 시급
```

### 복잡도 기반 시간 추정

| 복잡도 | 시간 범위 | 예시 |
|--------|----------|------|
| `low` | 4~8시간 | 기본 CRUD, 간단한 필터 |
| `medium` | 8~16시간 | 소셜 로그인, 이미지 업로드 |
| `high` | 16~32시간 | 실시간 채팅, 검색 엔진 |
| `very_high` | 32~64시간 | 에스크로 결제, 추천 알고리즘 |

## 프로젝트 수익성 추적

### 프로젝트 완료 후 기록할 데이터

```json
{
    "project_id": "uuid",
    "estimated_hours": 109.0,
    "actual_hours": 98.5,
    "accuracy_pct": 90.4,
    "contracted_amount": 3270000,
    "actual_cost": {
        "llm_api": 0,
        "infra": 15000,
        "total": 15000
    },
    "net_profit": 3255000,
    "hourly_effective_rate": 33046
}
```

### 수익성 대시보드 지표

| 지표 | 계산 | 용도 |
|------|------|------|
| **실질 시급** | 순이익 / 실제 투입 시간 | 내 시간의 실제 가치 |
| **견적 정확도** | 실제 시간 / 예상 시간 × 100 | Estimator 개선 근거 |
| **모듈 재사용률** | 재사용 모듈 기능 수 / 전체 기능 수 | 프레임워크 성장 추적 |
| **프레임워크 절약 효과** | 절약 시간 / 총 시간 × 100 | 프레임워크 ROI |
| **월 매출** | 해당 월 납품 프로젝트 합계 | 사업 성과 |

- MindExtract 운영 비용: 월 ~2만원~6만원
- **프로젝트 1건만 수주해도** 운영 비용 대비 압도적 흑자

## 시급 관리 전략

### 시급 설정 기준

| 시급 | 적합한 상황 |
|------|-----------|
| 25,000원 | 초기 포트폴리오 구축기, 소규모 프로젝트 |
| 30,000원 | 일반적인 수주 프로젝트 |
| 40,000원 | 전문 도메인 (핀테크, 의료 등) |
| 50,000원+ | 긴급 프로젝트 / 리피트 클라이언트 프리미엄 |

### 프레임워크 성장에 따른 시급 조정

```
초기 (모듈 5개 미만):
  → 시급 30,000원, 프레임워크 절약 효과 낮음
  → 실질 시급 ≈ 30,000원

성장기 (모듈 10~20개):
  → 시급 30,000원, 프레임워크 절약 30~50%
  → 동일 프로젝트를 더 빨리 납품
  → 실질 시급 ≈ 43,000~60,000원 (시간 절약분 반영)

성숙기 (모듈 20개+):
  → 시급 인상 가능 (40,000원+)
  → 또는 같은 시간에 더 많은 프로젝트 수주
```
