# 기술 아키텍처 — 프론트엔드 (Vibe Coding 전략)

## 핵심 원칙

### 개인 도구로서의 프론트엔드
MindExtract 내부 앱은 **맥북 로컬에서만 실행**되는 개인 도구이므로:
- 불특정 다수를 위한 화려한 랜딩 페이지 ❌ (랜딩은 별도 `mindextract.site`)
- 나의 **수주 워크플로우를 효율화하는 실용적 UI** ✅
- 클라이언트 인터뷰는 **대면/화상 미팅에서 내가 화면을 보여주며 조작**

### 프레임워크 선택: Next.js (App Router)
- **AI 코딩 도구 호환성 최우선** (v0, Cursor에 최적화)
- 다소 무겁더라도 AI가 완벽에 가까운 컴포넌트를 생성하는 생태계 활용

### 디자인 시스템: shadcn/ui
- 소스 코드가 프로젝트 내부에 존재 → **Cursor가 완벽히 파악**
- 커스터마이징 자유도 무한

## 바이브 코딩 워크플로우

### Step 1: v0에서 UI 뼈대 생성
```
[브라우저] → v0.dev
  → 자연어 디자인 프롬프트 입력
  → React/Next.js 컴포넌트 코드 자동 생성
  → 다운로드
```

### Step 2: Cursor IDE에서 로직 결합
```
[로컬] → Cursor IDE
  → v0 생성 컴포넌트 배치
  → 자연어로 FastAPI 백엔드 API 연동 지시
  → 프론트엔드 로직 자동 완성
```

### Step 3: 통합 테스트 및 미세 조정
```
npm run dev → 전체 플로우 E2E 테스트
  → Cursor에 추가 자연어 지시로 수정
```

## 페이지 구조 (App Router) — localhost:3000

```
app/
├── page.tsx                        # 메인 (대시보드로 리다이렉트)
│
├── dashboard/
│   ├── page.tsx                    # 📊 메인 대시보드
│   │                               #   - 진행 중 프로젝트 카드
│   │                               #   - 최근 활동
│   │                               #   - 월 수익 요약
│   │
│   └── clients/
│       ├── page.tsx                # 👥 클라이언트 목록
│       └── [clientId]/
│           └── page.tsx            # 클라이언트 상세 + 프로젝트 목록
│
├── project/
│   └── [projectId]/
│       ├── page.tsx                # 📋 프로젝트 상세
│       ├── spec/page.tsx           # 📄 정형 명세서 뷰어
│       ├── mapping/page.tsx        # 🧩 모듈 구성표
│       ├── estimate/page.tsx       # 💰 견적서
│       └── timeline/page.tsx       # 📅 진행 이력
│
├── interview/
│   └── [sessionId]/
│       └── page.tsx                # 💬 AI 인터뷰 채팅 (대면/화상에서 내가 조작)
│
└── framework/
    ├── page.tsx                    # 🔧 모듈 카탈로그 관리
    └── [moduleId]/
        └── page.tsx                # 모듈 상세 (사용 이력, 성숙도)
```

> 로컬 전용이므로 인증(next-auth) 불필요. 필요시 간단한 PIN 잠금만.

## 핵심 컴포넌트

| 컴포넌트 | 역할 |
|---------|------|
| `ProjectDashboard` | 전체 프로젝트 현황, 수익 요약 |
| `ClientList` | 클라이언트 목록/검색/필터 |
| `ChatInterface` | 멀티턴 AI 인터뷰 대화 UI (미팅 중 내가 조작) |
| `QuestionCard` | 객관식/추천형 질문 카드 (화면 공유 시 클라이언트에게 보여줌) |
| `SpecViewer` | 정형 명세서 렌더러 (JSON → 시각화) |
| `ModuleMappingView` | 모듈 구성표 (available/partial/unavailable) |
| `EstimateViewer` | 견적서 뷰어 + PDF 내보내기 |
| `FrameworkCatalog` | 모듈 카탈로그 관리 (CRUD) |
| `SpecDiffViewer` | 명세서 버전 간 diff |
| `ProjectTimeline` | 프로젝트 진행 이력 타임라인 |

## v0 프롬프트 예시

### 개인 대시보드
> "개발자용 프로젝트 관리 대시보드. 상단에 카드 3개(진행중 프로젝트 수, 이번 달 수익, 모듈 재사용률). 아래에 프로젝트 목록을 카드 그리드로 표시. 각 카드에 클라이언트명, 상태 배지(견적중/개발중/납품완료), 진행률 바. 다크 모드, 미니멀."

### AI 인터뷰 (미팅 중 화면 공유용)
> "AI 채팅 인터페이스. 깔끔하고 읽기 쉬운 디자인. AI 질문은 채팅 버블, 선택지는 클릭 가능한 카드(라디오). 상단에 프로그레스 바. 하단에 자유 입력 필드. 화상 미팅에서 화면 공유 시 클라이언트가 보기 좋은 레이아웃. shadcn/ui."

### 모듈 구성표
> "3단 분류 리스트. ✅ 재사용 가능(초록), ⚠️ 부분 재사용(노랑), ❌ 신규 개발(빨강). 각 항목에 모듈명, 절약 시간, 커스터마이징 시간 표시. 하단에 총 절약 시간 요약 바. 다크 모드."
