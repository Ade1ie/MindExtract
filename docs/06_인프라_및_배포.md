# 인프라 및 배포 전략

## 전체 구조

```
mindextract.site        → Vercel 무료 티어 (공개 랜딩)
localhost:3000 / :8000  → 맥북 로컬 실행 (내부 앱)
```

| | 랜딩 사이트 | 내부 앱 |
|---|---|---|
| **배포** | Vercel (무료) | 배포 안 함 (로컬) |
| **접근** | 공개 | 내 맥북에서만 |
| **비용** | $0/월 | $0/월 |

---

## 랜딩 사이트 배포: Vercel

### 설정
```bash
# Vercel CLI 설치
npm i -g vercel

# apps/site 폴더를 Vercel에 연결
cd apps/site
vercel

# 커스텀 도메인 연결
# Vercel 대시보드 → Settings → Domains → mindextract.site 추가
# DNS: A 레코드 또는 CNAME을 Vercel이 안내하는 값으로 설정
```

### 자동 배포 흐름
```
[Cursor IDE] → git push → [GitHub] → [Vercel 자동 빌드]
  → mindextract.site 업데이트 (SSL 자동, CDN 글로벌)
```

### Vercel 무료 티어 제한
- 빌드: 월 6,000분 (충분)
- 대역폭: 월 100GB (충분)
- 서버리스 함수: 연락 폼 메일 발송에 사용 가능

## 내부 앱 실행: 맥북 로컬

### 방법 A: 직접 실행 (가장 단순)

```bash
# 사전 준비
brew install python@3.11 node@20 postgresql@16

# PostgreSQL 시작
brew services start postgresql@16
createdb mindextract

# 터미널 1: 백엔드
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 터미널 2: 프론트엔드
cd apps/web
npm install
npm run dev   # → localhost:3000
```

### 방법 B: Docker Compose

```yaml
# docker-compose.yml
services:
  backend:
    build: ./backend
    ports: ["8000:8000"]
    volumes: ["./backend:/app"]
    environment:
      - DATABASE_URL=postgresql://user:pass@db:5432/mindextract

  frontend:
    build: ./apps/web
    ports: ["3000:3000"]
    volumes: ["./apps/web:/app"]

  db:
    image: postgres:16-alpine
    ports: ["5432:5432"]
    volumes: ["pgdata:/var/lib/postgresql/data"]
    environment:
      - POSTGRES_DB=mindextract
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=pass

volumes:
  pgdata:
```

```bash
docker-compose up   # 한 줄로 전체 실행
```

### 방법 C: Postgres.app (DB만)

```
Postgres.app 설치 → 시작 버튼 클릭
나머지는 방법 A처럼 직접 실행
→ DB 관리가 가장 편한 방법
```

## 확장 시나리오 (미래)

만약 나중에 클라이언트가 직접 인터뷰에 접근해야 할 필요가 생기면:

| 방법 | 난이도 | 비용 |
|------|--------|------|
| **ngrok 임시 터널** | 매우 쉬움 | 무료 (제한적) |
| **Cloudflare Tunnel** | 쉬움 | 무료 |
| **EC2 + Coolify 배포** | 중간 | 월 $10~$15 |

→ 현재는 불필요. 필요해지면 그때 판단.
